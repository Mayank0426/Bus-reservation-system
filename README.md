Bus Reservation System (C Programming)

A console-based Bus Reservation System developed using C programming.  
The project simulates a real-world bus ticket booking system.

Features:
- Book bus tickets
- Cancel reservations
- View bus details and seat availability
- Menu-driven console interface

Technologies Used:
- C Programming
- Structures
- Functions
- File Handling
- Conditional Statements & Loops
